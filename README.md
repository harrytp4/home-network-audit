\# 🔍 Home Lab Network Audit (\`network\_ping.py\`) A lightweight Python network audit tool built to dynamically verify active devices across a hybrid Linux/Windows home lab and streaming infrastructure. ## 📌 Features - \*\*Automated ICMP Verification:\*\* Audits local loopback, LAN IP interfaces, routers, and connected endpoints. - \*\*Cross-Platform Host Monitoring:\*\* Tracks both Ubuntu Linux nodes (HP Laptop, Steam Deck) and Windows gaming rigs (Alienware, Desktop PC). - \*\*WAN &amp; Internet Gateway Check:\*\* Verifies active internet connectivity against public DNS (\`8.8.8.8\`). - \*\*Clean Output Formatting:\*\* Outputs real-time visual \`ONLINE\` / \`OFFLINE\` indicators. ## 🖥️ Audited Network Map | Device | IP Address | OS / Role | | :--- | :--- | :--- | | \*\*HP Ubuntu (Loopback)\*\* | \`127.0.0.1\` | Local Machine Interface | | \*\*HP Ubuntu (LAN)\*\* | \`192.168.0.65\` | Systems Workstation | | \*\*Virgin Router / Gateway\*\* | \`192.168.0.1\` | Network Gateway | | \*\*Steam Deck\*\* | \`192.168.0.108\` | SteamOS / Handheld Node | | \*\*Alienware Laptop\*\* | \`192.168.0.176\` | Windows Host | | \*\*Gaming PC\*\* | \`192.168.0.179\` | Windows Host | | \*\*Google DNS\*\* | \`8.8.8.8\` | WAN / Internet Connectivity | ## 🚀 How to Run ### Prerequisites - Python 3.x - ICMP / Ping Echo Request enabled on target firewall rules (Windows Firewall ICMPv4 allow rule configured). ### Usage \`\`\`bash python3 network\_ping.py
